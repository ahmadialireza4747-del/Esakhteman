# Sandbox

این پوشه محیط آزمایشی پروژه Esakhteman است.

## هدف
قطعات و ماژول‌های جدید ابتدا در این بخش ساخته و آزمایش می‌شوند.

پس از تکمیل و موفقیت تست‌ها:
1. قطعه تأییدشده به ساختار اصلی پروژه همیار بنا منتقل می‌شود.
2. تست‌های نهایی در ساختار اصلی اجرا می‌شوند.
3. پس از تأیید انتقال، نسخه آزمایشی از Sandbox حذف می‌شود.

## اصل مهم
Sandbox محل نگهداری دائمی کد نیست؛ فقط مسیر ساخت، آزمایش و تأیید قطعات جدید است.
